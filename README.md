# SHOP-TUTORIAL 프로젝트

Spring Boot와 React를 이용한 쇼핑몰 리뷰 및 주문 관리 시스템

## 현재 진행 상황

* Spring Security 권한 설정 최적화 (리뷰 조회 권한 개방)
* 리뷰 CRUD 시스템 구축 (작성, 목록 조회, 수정, 삭제 로직 완성)
* JPA 성능 최적화 (Fetch Join 도입)
* 주문 관리 기능 확장 (취소 및 반품 신청 버튼 연동)
* 사용자 경험(UX) 개선 (모달 제어 및 인라인 편집 도입)

## 주요 트러블슈팅 로그

### 2026-02-27 트러블슈팅
* **에러: 데이터베이스 및 터미널 내 한글 깨짐 (??????) 발생**
  * **원인**: MySQL 컨테이너의 기본 캐릭터셋이 `latin1`으로 설정되어 한글 데이터를 처리하지 못함. 또한 PowerShell 인코딩과 MySQL 클라이언트 간의 정합성 불일치 발생.
  * **해결**: 컨테이너 생성 시 `--character-set-server=utf8mb4` 옵션을 부여하여 재생성하고, 접속 시 `--default-character-set=utf8mb4` 옵션을 명시하여 터미널 출력 문제 완벽 해결.

* **에러: git push 시 `src refspec main does not match any` 발생**
  * **원인**: 로컬 저장소의 기본 브랜치명이 `master`로 되어 있으나 원격지의 `main` 브랜치로 푸시를 시도하여 매칭 실패.
  * **해결**: `git branch -M main` 명령어로 로컬 브랜치명을 강제 변경한 후 `git push -u origin main`으로 정상 전송.

### 2026-02-24 트러블슈팅
* **에러: 주문 취소 시 `MissingPathVariableException` 발생 (401/500 에러)**
  * **원인**: 스프링 부트 3.2 버전부터 컴파일러가 PathVariable 이름을 자동으로 추론하지 못하는 이슈 발생. 또한, 에러 발생 시 `/error` 경로에 대한 보안 설정이 미비하여 프론트엔드에 401로 잘못 전달됨.
  * **해결**: `@PathVariable("orderId")`와 같이 이름을 명시적으로 선언하고, 인텔리제이 `Rebuild Project`를 통해 컴파일 캐시를 갱신하여 해결.

* **에러: 리뷰 등록 후 별점이 화면에 표시되지 않는 현상**
  * **원인**: 백엔드 `ReviewResponse` DTO에 `rating` 필드가 누락되어 데이터가 전달되지 않았고, 프론트엔드에서도 해당 값을 렌더링하는 로직이 부재함.
  * **해결**: DTO에 필드 추가 및 프론트엔드에서 `repeat()` 함수를 활용한 별점 UI 구현.

### 2026-02-20 트러블슈팅
* **에러: 상품 사진 업로드 시 `imageUrl` 값이 null로 저장되는 현상**
  * **원인**: 프론트엔드에서 사진을 먼저 업로드하고 반환받은 URL을 `productData`라는 새 객체에 잘 담았으나, 정작 서버로 보내는 `fetch` 함수의 `body`에는 옛날 상자인 `formData`를 던져버리는 휴먼 에러 발생.
  * **해결**: `body: JSON.stringify(formData)`를 `body: JSON.stringify(productData)`로 수정하여 백엔드 DTO와 완벽하게 데이터 매핑 성공.

### 2026-02-14 트러블슈팅
* **UI 오류: 모달 외부 클릭 시 창 닫힘 현상**
  * **원인**: Overlay 영역에 `onClick` 닫기 이벤트가 설정되어 리뷰 작성 중 데이터가 유실될 위험 발생.
  * **해결**: 배경 클릭 이벤트를 제거하고 전용 [닫기] 버튼을 통해서만 제어되도록 수정하여 UX 안정성 확보.
* **에러: Each child in a list should have a unique "key" prop**
  * **원인**: 리뷰 목록 및 수정 모드 전환 시 최상위 요소에 고유 Key가 누락되거나 ID값이 중복됨.
  * **해결**: `rev-${rev.id}` 형태의 접두사 기반 고유 Key 전략을 도입하여 리액트 렌더링 경고 완전 해결.
* **백엔드 오류: API 매핑 시 username: null 유입**
  * **원인**: 삭제/수정 컨트롤러와 서비스 간의 매개변수 전달 과정에서 필드명 불일치 및 토큰 추출 로직 누락.
  * **해결**: `Authentication` 객체에서 직접 `getName()`을 추출하는 방식으로 변경하여 보안 및 데이터 정확성 강화.

### 2026-02-13 트러블슈팅
* **에러: InvalidDefinitionException (ByteBuddyInterceptor)**
  * **원인**: Jackson이 Hibernate의 지연 로딩용 프록시 객체를 직렬화하지 못해 500 에러 발생.
  * **해결**: DTO 계층을 추가하고, 순수 객체로 변환하여 반환하는 방식으로 해결.
* **에러: N+1 성능 이슈 (JPA)**
  * **원인**: 리뷰 목록 조회 시 각 리뷰마다 유저 정보를 가져오기 위해 추가 SQL 실행.
  * **해결**: JPQL에서 `JOIN FETCH`를 사용하여 단일 쿼리로 최적화.
* **UI 오류: 리뷰 입력창/삭제 버튼 미출력**
  * **원인**: React 엄격한 비교(`===`) 시 문자열 ID와 숫자 ID 간의 타입 불일치.
  * **해결**: 비교 대상 양측에 `String()` 형변환을 적용하여 해결.
