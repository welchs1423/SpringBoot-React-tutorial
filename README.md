### 2. 주요 트러블슈팅 로그 (2026-02-13)

* **에러: InvalidDefinitionException (ByteBuddyInterceptor)**
    * **원인**: Jackson이 Hibernate의 지연 로딩용 프록시 객체를 직렬화하지 못해 500 에러 발생.
    * **해결**: DTO 계층을 추가하고, 반복문을 통해 순수 객체로 변환하여 반환하는 정공법으로 해결.
* **에러: N+1 성능 이슈 (JPA)**
    * **원인**: 리뷰 목록 조회 시 각 리뷰마다 유저 정보를 가져오기 위해 리뷰 개수만큼의 추가 SQL 실행.
    * **해결**: JPQL에서 `JOIN FETCH`를 사용하여 단일 쿼리로 유저 정보까지 즉시 로딩하도록 최적화.
* **UI 오류: 리뷰 입력창/삭제 버튼 미출력**
    * **원인**: React 엄격한 비교(`===`) 시 문자열 ID와 숫자 ID 간의 타입 불일치.
    * **해결**: 비교 대상 양측에 `String()` 형변환을 적용하여 타입 일치 후 로직 정상화.
